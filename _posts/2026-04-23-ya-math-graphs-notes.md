В постах такого типа я буду записывать конспекты глав из хэндбука «Математика для анализа данных» от Яндекса. По большей части я делаю это для себя, но вы тоже можете ознакомится с ними.

Посты можно искать по тэгу `яндекс_мдад`.

$$G = (V, E)$$

- $V$ — множество вершин. Чтобы граф существовал, нужна хотя бы одна вершина, то есть $|V| \geq 1$.
- $E$ — множество ребер.

# Виды вершин

- Изолированная вершина — не связана ни с одной другой вершиной.
- Висячая вершина — из вершины выходит единственное ребро.
- Шарнир — вершина, при удалении которой граф теряет связность, то есть разделяется на меньшие графы.

# Виды ребер

- Смежные ребра — имеют общую вершину.
- Кратные ребра — соединяют одну и ту же пару вершин.
- Направленные ребра — имеют направление. Если граф ориентированный, то ребра $(v_1, v_2)$ и $(v_2, v_1)$ не равны.
- Петля — ребро вида $(v, v)$. Оба конца петли являются одной вершиной.
- Мост — ребро, после удаления которого становится больше компонент связности. То есть граф становится менее связным.

# Инцидентность и смежность

Вершина и ребро называются инцидентными, если данное ребро соединяет данную вершину с другой вершиной.

- Инцидентное (смежное) ребро — соединяет данную вершину с другой вершиной.
- Инцидентная (прилежащая) вершина — конец смежного ребра.

Инцидентность относится исключительно к паре «вершина — ребро». Каждая вершина, которая является концом какого-то ребра, инцидентна.

Смежность же описывает отношение в парах «ребро — ребро» или «вершина — вершина».

- Смежные вершины — соединены общим ребром.
- Смежные ребра — имеют общую вершину.

# Путь

Путь — это последовательность вершин, в которой каждая точка пути связана с предыдущей. То есть по пути можно «пройти» из одной точки в другую.

- Простой путь — путь, в котором все вершины различны, то есть каждая вершина попадается один раз на протяжении всего пути.
- Цикл — путь, который начинается и заканчивается в одной и той же вершине.

Длина цикла — это количество ребер, входящих в него. Если в цикле все вершины различны, то цикл называется простым.

# Плотность графа

Полный граф — граф, в котором каждая пара вершин соединена равно одним ребром.

Как найти максимальное количество ребер? Пусть $V$ — количество вершин.

$$\frac{V(V - 1)}{2}$$

Для неориентированного графа.

$$V(V - 1)$$

Для ориентированного графа. Здесь деление на два не нужно, так как для каждой пары вершин можно провести два разных ребра.

- Плотный граф — число ребер близко к максимальному возможному.
- Разреженный граф — число ребер очень мало.

# Подграфы

Для начала дадим строгое математическое описание.

$$H = (V', E')$$

Где $H$ — это подграф, вершины ($V'$) и ребра ($E'$) которого принадлежат множествам графа: $V' \subseteq V$ и $E' \subseteq E$.

# Как представить граф?

- Список ребер — храним список всех ребер без вершин. Прост в реализации и удобен в использовании. Использовать нужно при малом количестве ребер, то есть в разреженном графе.
- Матрица смежности — храним информацию о вершинах в разреженной матрице $V \times V$. Если между `a` и `b` есть ребро, то `m[a][b]` будет равно единице или любому другому флагу наличия связи.
- Набор степных вершин — граф представляется в виде списка степеней вершин. Этот метод полезен для анализа свойств графа, таких как плотность и распределение степеней вершин. С помощью этого представления нельзя точно восстановить структуру графа.
